АЛЛЕЯ ХВОСТИКОВ — ЧТО ЗАГРУЗИТЬ НА GITHUB
==========================================

ЭТО ОБНОВЛЕНИЕ (важно!): загрузить ДВА файла вместе —
    index.html и stars.js
Кнопка «Add file» → «Upload files» → перетащить оба → Commit changes.
GitHub сам заменит старые файлы с теми же именами.
Если загрузить только один из них, список звёздочек может не показываться.

ПОСЛЕ ЭТОГО ОБНОВЛЕНИЯ (впредь навсегда):
================================================================
Новые звёздочки вы добавляете сами, ОДНИМ файлом:

1. GitHub → файл stars.js → иконка КАРАНДАША (Edit).
2. Допишите строку между словами СПИСОК и КОНЕЦ:

       номер, кличка, надпись, дата

   Пример: 18, Барсик, Спи спокойно, друг, 13.11.2026
   Номер = номер платежа Продамуса. Кавычки не нужны — просто текст.
   Строка не должна начинаться с //.
3. Зелёная кнопка «Commit changes».
4. Звёздочка засветится сразу, для ВСЕХ посетителей — кэш этого
   файла отключён, обновлять страницу можно без Ctrl+F5.

Если звёздочка не появилась:
   • нажата ли зелёная кнопка «Commit changes»;
   • не начинается ли строка с // ;
   • обновите страницу (F5).
