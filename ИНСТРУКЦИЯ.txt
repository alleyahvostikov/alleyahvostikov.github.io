АЛЛЕЯ ХВОСТИКОВ — ЧТО ЗАГРУЗИТЬ НА GITHUB
==========================================

ШАГ 0. РАСПАКОВКА
Скачайте архив alleya-hvostikov-github.zip и распакуйте его
(правая кнопка мыши → «Извлечь всё»). Внутри — папка с 8 файлами,
имена уже правильные, переименовывать ничего не нужно.

ШАГ 1. УДАЛИТЬ СТАРЫЕ ФАЙЛЫ ИЗ РЕПОЗИТОРИЯ (если есть)
GitHub → репозиторий alleyahvostikov/alleyahvostikov.github.io.
Удалите, если они там есть:
    oferta (4).docx
    oferta.docx
    policy.docx
    soglasie.docx
Как удалить: откройте файл → кнопка «...» → Delete file → Commit changes.

ШАГ 2. ЗАГРУЗИТЬ НОВЫЕ ФАЙЛЫ (РОВНО 8)
Кнопка «Add file» → «Upload files» → перетащите ВСЕ 8 файлов
из распакованной папки:

    index.html      — главная страница (небо, звёздочки, поиск)
    stars.js        — СПИСОК ЗВЁЗДОЧЕК (редактируете только его)
    oferta.html     — оферта (страница)
    policy.html     — политика (страница)
    soglasie.html   — согласие (страница)
    oferta.pdf      — оферта (скачиваемый файл)
    policy.pdf      — политика (скачиваемый файл)
    soglasie.pdf    — согласие (скачиваемый файл)

Нажмите зелёную кнопку «Commit changes».
Через 1–2 минуты откройте https://alleyahvostikov.github.io и обновите
страницу (Ctrl+F5).

КАК ДОБАВЛЯТЬ ЗВЁЗДОЧКИ ДАЛЬШЕ (после каждой оплаты)
═══════════════════════════════════════════════════════════════
1. На почту istokipamyati@yandex.ru приходит письмо от Продамуса:
   в нём ФИО покупателя, кличка питомца, надпись и НОМЕР ПЛАТЕЖА.
2. Сверьте надпись: без мата, рекламы и чужих авторских текстов
   (это модерация по оферте, до 3 рабочих дней).
3. На GitHub откройте stars.js → карандаш (Edit) → допишите строку
   между строками СПИСОК и КОНЕЦ в формате:

        номер|кличка|надпись|дата

   Номер = номер платежа. Символ | внутри текста не использовать.
4. Кнопка «Commit changes» — через минуту звёздочка светится на небе,
   находится поиском по кличке и учитывается в счётчике «Освещено...».

Если ошиблись в строке — просто исправьте её так же: карандаш → правка → Commit.
Сайт хранит все версии (history), ничего не потеряется.

КОГДА ПОЯВИТСЯ ОПЛАТА (Продамус)
═══════════════════════════════════════════════════════════════
Сейчас кнопка оплаты показывает «Приём заявок откроется в ближайшее
время» — так и задумано до подключения Продамуса.

счётчик Яндекс Метрики и баннер согласия на аналитические cookie.
